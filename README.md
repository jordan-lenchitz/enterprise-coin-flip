# Enterprise-Grade Coin Flip

A B2B SaaS-ready microservice that flips a coin using True Quantum Randomness™.

## The Architecture
Why use `random.randint(0, 1)` when you can:
1. Dynamically provision an ephemeral Google Cloud Project.
2. Enable the billing and Quantum Computing APIs.
3. Authenticate with a Quantum Processing Unit (QPU).
4. Run a Hadamard gate on a single qubit to achieve superposition.
5. Measure the qubit to collapse the wave function into a truly random `0` or `1`.
6. Aggressively tear down the entire GCP project to avoid lingering costs.

Time complexity: `O(1)`
Financial complexity: `O($$$)`
Time to execution: ~4.2 minutes per flip.

## Quick Start
```bash
pip install -r requirements.txt
python main.py
```
